# AGENTS.md

Orientações para todos os agentes que trabalham neste repositório.

## Tecnologias

- Next.js com App Router e React.
- JavaScript e CSS.

Consulte o `package.json` para as versões das dependências, o requisito de Node.js e os scripts disponíveis.

## Comandos disponíveis

- `npm run dev`: inicia o servidor de desenvolvimento.
- `npm run build`: gera a versão de produção.
- `npm start`: inicia o servidor de produção após o build.
